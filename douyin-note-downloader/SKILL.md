# 抖音图文无水印下载

使用随附脚本完成浏览器加载、作品数据解析、图片下载、尺寸校验和 ZIP 打包，不要重复手写解析流程。

## 执行

1. 确认目标是抖音图文帖。视频请求改用其他流程。
2. 在当前工作区运行：

```bash
python3 "<skill目录>/scripts/douyin_note_downloader.py" "<用户链接或分享文本>" -o "<当前工作区/输出目录>"
```

3. 省略 `-o` 时，脚本在当前终端目录创建 `<帖子标题>_无水印壁纸/`。添加 `--no-zip` 可只保存图片。
4. 保留脚本输出的数量、尺寸和错误信息。失败时保留已下载文件，报告失败原因，不要把部分结果称为全部完成。

## 环境与排障

- 需要 Python 3、curl、本机 Kimi WebBridge 及已连接的浏览器扩展；不需要第三方 Python 包，也不要求用户手动复制 Cookie。
- 脚本会在连接失败时尝试启动 WebBridge。仍失败时，引导用户启用浏览器扩展并确认帖子在浏览器中可访问。
- 页面出现登录或验证码时，让用户在浏览器完成操作后重试，不要绕过验证。
- 页面数据结构变化导致解析失败时，检查 `scripts/douyin_note_downloader.py` 中的 `wait_for_embedded_data` 和 `extract_images`。

## 下载原则

- 使用作品 `images` 数据中的 `urlList` 展示图地址，优先 JPEG。
- 不使用带 `tplv-dy-water-v2` 的 `downloadUrlList` 作为“无水印”来源。
- “无水印”指未额外添加平台下载水印；保留图片本身已有的标题、作者署名或画面文字，不用涂抹、裁切或生成式修复伪装成原图。
- 默认保留帖子顺序、原始尺寸和现有文件；ZIP 只包含本次确认成功的图片。

## 交付

- 给出图片数量、保存目录和 ZIP 链接；说明竖图与横图数量（适用于壁纸请求）。
- 若图片自身带署名，明确告知用户。
- 只有实际校验成功后，才声称下载或打包完成。
